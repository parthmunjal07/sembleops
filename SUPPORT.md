# Support

SembleOps is community-maintained, self-hosted software. It comes with no service-level agreement, uptime promise, warranty, managed hosting, account recovery, or guaranteed response time.

Use the repository's issue tracker for reproducible bugs and documentation gaps. Use discussions, when enabled, for setup questions and ideas. Search existing conversations before posting and provide:

- the SembleOps version or commit;
- operating system and Node.js version;
- local, container, or hub-plus-worker deployment mode;
- redacted logs and minimal reproduction steps;
- what you expected and what occurred.

Never post API keys, access tokens, private prompts, task contents, database files, repository code, or personal data. Follow [SECURITY.md](SECURITY.md) for vulnerabilities.

Operators are responsible for their own infrastructure, data, backups, provider accounts, usage charges, and compliance obligations. Contributors cannot access or repair a self-hosted installation unless the operator separately grants access, which the project does not request or recommend.
